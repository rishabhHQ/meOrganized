# 📖 Wikipedia of Everything — Rishabh Paudel

> *"Well it's not for you but on the internet everything is for exploring so you can also be a part of it yayaya 🥳"*

A personal Wikipedia-style page built with plain HTML and CSS. No frameworks, no build tools — just vibes and serif fonts.

---

## 🗂️ Project Structure

```
.
├── index.html       # The main page
└── style.css        # Wikipedia-inspired styles
```

## 🚀 Getting Started

No setup needed. Just open `index.html` in a browser.

```bash
# Clone or download, then:
open index.html
```

Or serve it locally if you prefer:

```bash
npx serve .
# → http://localhost:3000
```

## ✨ Features

- Wikipedia-style layout — serif fonts, grey borders, classic link colors
- Floating **infobox** with all social/contact links
- **Table of Contents** with section anchors
- Responsive — infobox stacks on mobile
- Zero dependencies
